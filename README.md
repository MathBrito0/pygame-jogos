# 🎮 PyGame Learning

Recreating classic games in Python with Pygame, one folder at a time.

## 📖 About

This repository started as one of those ideas that pop into your head in the middle of the night: combining the goal of learning to create games with the desire to recreate famous games in Python.

## ▶️ How to run

1. Clone the repository
2. Install dependencies
3. Enter the game folder and run
